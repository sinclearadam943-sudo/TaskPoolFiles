# 通用自动化测试框架设计

## 框架架构

支持多种测试类型统一管理：

```
┌─────────────────────────────────────────────────────────────┐
│                测试发现                                     │
│  按文件名规则扫描，找到测试用例                              │
├─────────────────────────────────────────────────────────────┤
│                Fixture 管理                                 │
│  setUp / tearDown ，依赖注入，scope控制（function/class/session）│
├─────────────────────────────────────────────────────────────┤
│                执行器                                       │
│  顺序执行 / 并行执行                                         │
├─────────────────────────────────────────────────────────────┤
│                结果收集                                     │
│  成功/失败统计 / 异常信息 / 执行时间                           │
├─────────────────────────────────────────────────────────────┤
│                报告生成                                     │
│  HTML报告 / JSON报告 / 覆盖率统计                             │
└─────────────────────────────────────────────────────────────┘
```

## 支持测试类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 单元测试 | 测试单个函数/类 | 底层库函数 |
| 集成测试 | 测试多个模块一起工作 | API接口、数据库集成 |
| 端到端测试 | 从用户操作全链路测试 | UI流程、完整业务流程 |

## Fixture 设计

Fixture 是测试前准备、测试后清理：

```python
# 示例
@pytest.fixture(scope="session")
def database_connection():
    # session scope: 整个测试会话只创建一次
    conn = create_test_db()
    yield conn  # 提供给测试用
    conn.close()  # 测试结束后清理

@pytest.fixture(scope="function")
def clean_data():
    # function scope: 每个测试都重新来
    setup_test_data()
    yield
    rollback()
```

**scope 选项：**
- `function`：每个测试函数运行一次
- `class`：每个测试类运行一次
- `module`：每个模块运行一次  
- `session`：整个测试会话运行一次

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 单元测试 | 测试单个函数/类 | 底层库函数 |

## Fixture 设计

Fixture 是测试前准备、测试后清理：

```python
# 示例
@pytest.fixture(scope="session")
def database_connection():
    # session scope: 整个测试会话只创建一次
    conn = create_test_db()
    yield conn  # 提供给测试用
    conn.close()  # 测试结束后清理

@pytest.fixture(scope="function")
def clean_data():
    # function scope: 每个测试都重新来
    setup_test_data()
    yield
    rollback()
```

**scope 选项：**
- `function`：每个测试函数运行一次
- `class`：每个测试类运行一次
- `module`：每个模块运行一次  
- `session`：整个测试会话运行一次

## 并行测试执行

使用多进程并行执行测试，加快整体速度：

- 按文件/模块拆分，每个进程处理一个文件
- 进程间隔离，不会互相干扰
- 自动检测CPU核心数设置进程数

| 测试数据库事务回滚 | 不污染真实测试数据 |

## 最佳实践

1. **测试隔离**：每个测试之间不共享状态，避免测试互相影响
2. **快速反馈**：单元测试运行要快，开发频繁运行
3. **分层测试**：单元测试多写，集成测试适量，E2E少写
4. **稳定可靠**：不要写随机失败的测试，不稳定测试不如没有
5. **测试代码和生产代码一样维护**
